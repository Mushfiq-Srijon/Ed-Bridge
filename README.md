Academic Resource Sharing Platform for Students

## Project Info
- **Team Members**: 4 developers
- **Duration**: 15 weeks
- **Stack**: .NET 6 (ASP.NET Core) + React + MySQL

## Quick Start

### Backend
```bash
cd EdBridge.API
dotnet run
```

### Frontend
```bash
cd frontend
npm install
npm start
```
